# استخدام sbar-checkpoint

اسم الاستدعاء في Codex: `$sbar-checkpoint`. في Claude Code وHermes: `/sbar-checkpoint`.

في تشغيل Hermes دون واجهة تفاعلية استخدم `--skills sbar-checkpoint`، لأن نص الطلب لا يضمن تفسير الأمر الذي يبدأ بشرطة مائلة.

المهارة لها محرك واحد وتعليمات مخصصة لكل مضيف. تثبيت Codex وClaude Code وHermes يستخدم مجلد المهارات الخاص بالمضيف أو ملفه الشخصي الحالي. اقرأ [جدول المضيفين](hosts.md) وملف المضيف المناسب. لا يغير المثبت إعداداتك ولا يثبت hooks، ويرفض استبدال نسخة موجودة.

للانتقال بين المضيفين أبق ملفات المشروع والخطة وسجل التشغيل في المسار نفسه. أوقف الأعمال التابعة أولًا، ثم اطلب من المضيف الجديد قراءة الحالة الحالية. لا يبدأ تشغيلًا جديدًا ولا يعيد أمرًا مكتملًا. الأدلة القديمة أو مراجعة كتبت قبل تعديل المصدر تحتاج تجديدًا.

مثال طلب:

«استخدم sbar-checkpoint لإضافة حفظ فاتورة المورد وربطها بالحركة المالية. نفذ ضمن بيئة اختبار معزولة، واختبر تكرار الطلب وحدود المؤسسة، وراجع التنفيذ بوكيل مستقل. لا تنشر.»

المهارة تقرأ قواعد المشروع وتحدد المتطلبات والمراحل وأوامر الفحص قبل العمل. تحفظ خطة التشغيل والأدلة خارج ملفات المصدر، وتعيد التحقق من صلاحيتها قبل اعتماد النتيجة. لا تحتاج خدمة بعيدة أو مفتاح API لمحرك الحالة؛ الوكيل نفسه وأدواته يأتون من المضيف الذي تستخدمه.

## ما يظهر لك

- نتيجة كل مرحلة ومتطلباتك التي تغطيها.
- فحوص فعلية ومخرجاتها، بدل خانة نجاح يكتبها المنفذ.
- حكم مراجع مستقل مربوط بنسخة المصدر والخطة.
- دليل قديم عند تغير الملفات المؤثرة.
- حالة توقف واستئناف دون إعادة أمر ذي رقم تشغيل مكتمل.
- قبول محلي منفصل عن النشر أو التحقق عند مزود خارجي.

## الأوضاع

`feature` للميزات، و`repair` للإصلاح، و`migration` للترحيل، و`audit` للتدقيق دون تعديل، و`plan` للتخطيط فقط. المهارة تعليمات للمضيف ومحرك تحقق محلي، وليست sandbox يمنع كل أمر غير مصرح به. حماية القراءة فقط أو البيانات الحساسة تحتاج صلاحيات المضيف المناسبة.

## الموافقات

الوضع `delegated` يحترم التفويض القائم ويكمل العمل دون سؤال عند كل مرحلة. `milestone` و`checkpoint` يسجلان قرارًا فعليًا عندما يلزم. حقول الموافقة سجل للتفويض وليست توقيعًا موثوقًا لهوية صاحب القرار. المهارة لا تعطي صلاحيات إضافية ولا تتضمن أمر نشر.

## التوقف

اطلب التوقف كما تفعل عادة، وينفذ الوكيل `pause` أو `cancel` ويوقف العملية التي يملكها. يتابع مشغل الفحص حالة التشغيل ويقتل مجموعة العمليات التابعة عند التوقف أو انتهاء المهلة. عمليات تنشئ جلسة مستقلة عمدًا تقع خارج هذا الحد؛ لا تستخدم فحصًا لإطلاق خدمات مشتركة طويلة العمر.

عند الاستئناف يعيد الوكيل فحص المصدر والأدلة. رقم التشغيل يمنع تكرار الفحص نفسه، لكنه لا يغني عن idempotency في تطبيق الدفع أو حركة المخزون. لا تُعد تشغيل إجراء خارجي ملتبس النتيجة قبل المصالحة.

## حدود النسخة

النواة مبنية بـPython والمكتبة القياسية لـPOSIX. تشغّل الفحوص التلقائية المحرك على Linux بإصدارات Python 3.10 و3.12 و3.14، وعلى macOS بإصدار 3.12. هذه فحوص للمحرك وليست شهادة لمزودات الوكلاء. الهوية المسجلة للمراجع لا تثبت وحدها أنه وكيل مستقل، ويحتاج المراجع سياقًا مستقلًا عن المنفذ. لا يمكن لمحرك محلي يملكه وكيل بصلاحية كتابة كاملة أن يمنع ذلك الوكيل من تغيير المحرك نفسه.

مراجعة الصور والتفاعل تحتاج أدوات المضيف الفعلية، ولا يحكم المحرك بنفسه على جمال الواجهة أو وصوليتها. اختبار ملفات الصور في مجموعة قبول المحرك يثبت سلامة الربط فقط. مزودات الإنتاج وRLS الحقيقية وأجهزة أخرى تحتاج تجارب في بيئاتها قبل ادعاء دعمها.
